플링의 핵심 기능

가까이에서는?

플링을 이용하는 사람끼리 서로 계좌번호를 자동 연결받아 송금!

멀리서는?

계좌번호, 전화번호 입력으로 간편하게 송금!

웹에서는?

링크 하나만 보내면 송금 끝!

사용 방법

1

"송금" 버튼 클릭

앱에서 송금 버튼을 누르세요

2

근처에 있는 사람 클릭

블루투스로 자동 감지된 사용자를 선택

3

오픈뱅킹으로 송금!

안전하고 빠르게 송금 완료

왜 플링인가?

편하게 송금해요!

계좌번호를 불러주지 않아도 됩니다. 앱만 켜면 근처 사용자와 자동으로 연결됩니다.

빠르게 송금해요!

3초만에 송금이 완료됩니다. 더 이상 계좌번호를 잘못 듣고 다시 물어볼 필요가 없습니다.

안전하게 송금해요!

자체 암호화 기술과 오픈뱅킹 시스템으로 안전하게 송금할 수 있습니다.

언제 어디서나 편하게 송금해요!

스마트폰만 있으면 언제 어디서나 간편하게 송금할 수 있습니다.

플링과 함께하세요

더 편리한 송금의 미래를 경험하세요
